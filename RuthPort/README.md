## 🚢 Deploying to Vercel

1. Push this repository to GitHub (`github.com/ruthrane25/RuthPort`).
2. Log into [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your repository. Vercel automatically detects Vite with:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Click **Deploy** — your portfolio is live worldwide in seconds!
